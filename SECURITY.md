# Security policy

## Reporting a vulnerability

Report privately through GitHub's private vulnerability reporting on this
repository ("Report a vulnerability" under the Security tab). Do not open a
public issue for a vulnerability.

You should get an acknowledgement within 7 days and an assessment within 14. If
a fix is needed, we will agree a disclosure date with you before publishing.

Most valuable here: a way to reach the admin console without the admin password,
a way to get code into a server through the image, or anything that lets an
update or a backup destroy a save it was not asked to touch.

## The admin console

RCON authenticates with `ADMIN_PASSWORD`. The container refuses to run it with
an empty or well-known password: it generates a random one, stores it at
`/config/admin_password` with mode 600, and never logs the value. Read it with
`docker exec <container> cat /config/admin_password`.

The shipped compose file binds RCON to `127.0.0.1`. It is an admin port and is
never forwarded on a router; see `docs/INSTALL.md` for which ports are public
and which stay private.

## What this repository never contains

This is a public repository for a public image. It carries no detail of any real
deployment: no addresses, hostnames, network layout or firewall rules, in the
code, the documentation, commit messages, PR bodies or issues. Examples use
`192.168.1.50` and the documentation range `203.0.113.0/24`.

## Secrets

No secret belongs in this repository, in a string literal, in a build argument
or in an example file. Passwords arrive at run time through the environment, or
are generated by the container and stored in `/config`.

## Where findings live

Bills of material for the published images are public, attached to each image as
provenance and SBOM attestations. Audit findings, unpatched vulnerabilities and
licence exceptions under review are kept privately, not in this repository's
issues or workflow artifacts.

## Standard

This repository conforms to the Absolute engineering standard; its security
baseline is layered L1 to L7, and this repository's answers, including its open
exceptions, are in [`.absolute/policy.yml`](.absolute/policy.yml). The check
that enforces them is vendored under
[`.absolute/standard/`](.absolute/standard/PROVENANCE.md).
